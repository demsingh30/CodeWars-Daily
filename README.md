#Codewars Practice

My daily JavaScript reps. Every kata here was solved on Codewars and pushed to GitHub so I can track my progress over time.

How this repo works

Each file holds:

The challenge — the kata description, copied in as a comment
My first solution — whatever I got working first
The refactor (when there is one) — a cleaner version after reviewing it

Keeping both versions shows how my thinking changes, not just the final answer.
